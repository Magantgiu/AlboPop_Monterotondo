AlboPOP Monterotondo
Un aggregatore RSS non ufficiale per l'albo pretorio del Comune di Monterotondo.
Cos'è AlboPOP?
AlboPOP è un'iniziativa civica che mira a rendere più accessibili gli albi pretori dei comuni italiani, trasformandoli in feed RSS facilmente consultabili.
Come funziona?
Questo script Python esegue uno scraping dell'albo pretorio ufficiale del Comune di Monterotondo e genera un feed RSS con le ultime pubblicazioni. Il processo è automatizzato tramite GitHub Actions e viene eseguito quotidianamente.
Feed RSS
Il feed RSS è disponibile qui: albopop_monterotondo.xml
Dettagli tecnici

Lo script è scritto in Python e utilizza le librerie requests e BeautifulSoup per lo scraping
Il feed RSS viene generato con la libreria feedgenerator
L'automazione è realizzata tramite GitHub Actions con esecuzione programmata giornaliera
I feed storici vengono archiviati nella directory archive
